## 1. 总体结构

右栏（"她的世界"）不是一张画，而是**一串"计算可视化"场景**，平均每 6 秒换一幕：
参数递减计数 → RUN 模拟 → 损失曲线绘制 → 方块扩散/文字鲸鱼 → PCA/T-SNE 点云
→ 二进制瀑布 → 正弦波扫描 → 频谱条 → **角色精灵去噪生成** → 内核/特征图/注意力热图
→ 终端 Y/N → 进度条 → 100% → 代码编辑器 → 仪表盘 → 星系粒子 → 波形 → 迷宫寻路
→ "07 → EXECUTION" → EXECUTE 文字弹幕 → 红色告警 → "you: not found" → "love" 代码
→ 星空/烛火 → 空屏收尾。

## 2. 场景内部的动效词汇（14 种，全部实测）

1. **打字机**：消息/代码逐字出现（左栏实测 56.5~59.5s："有什么可以帮你的吗？"逐字生成）。
2. **块状光标**：活跃文本尾部 `▍` 闪烁；`unite▍`、`deeply▍`。
3. **计数滚动**：`sft-step-1001→1160`、`1.7K tok · 缓存命中 82%→83%`、
   `activations 2176/4096→4012/4096`、`$5.576M GPU hours`、去噪 `t=522→265→...→009`。
4. **进度条/推进轨道**：填充条、行进中的小方块（`flatten → attention`、精灵行）。
5. **行进式绘制**：虚线沿对角线一步步长出来、曲线随数据延伸、读数牌跟着跳（0.51→0.72）。
6. **网格单元活动**：热图/迷宫/二进制格按序点亮、脉动、被"扫过"。
7. **文字剪影（文字鲸鱼）**：整只鲸鱼轮廓由重复文字 "seekdeepseek…" 排成，
   字形内容持续流动 → 整只鲸表面在闪变。帧差图显示全鲸参与变化。
8. **去噪显影**：角色精灵面板逐帧从噪点 → 雾状 → 成形，`t=` 步数递减；
   同格内容真实地在变（不是抖动）。
9. **瀑布/矩阵滚字**：`IFICANITE` 等碎片的垂直字符瀑布、`EXECUTE` 横向弹幕滚动。
10. **大像素字揭示**：`07` → `EXECUTION` 用点阵大步进打字/填充。
11. **日志逐行追加**：绿色 `[executed]` 日志一行行往下刷。
12. **UI 微动**：发送按钮活动环旋转、状态点脉动、工作流列表高亮逐级步进
    （NOISE→UNET.DOWN→ATTN→…）、编辑标记闪现。
13. **粒子环境**：结尾星空缓慢漂移、小烛火忽明忽暗。
14. **场景切换**：以硬切为主，少数带入场（大字样揭示、角色肖像登场）。

## 3. 关键结论

- **全片几乎没有"整幅图抖动/摇摆"**。动效全部是**局部的、语义的**：
  字在打、数在跳、条在填、图在变形、粒子在飘。
- 角色/图像不是"被晃动"，而是**生成、显影、变形**（去噪面板就是逐帧变内容）。
- 左右两栏共用同一套动效词汇（打字机/计数/光标/进度）。
- 右栏的本质是**永远在更新的信息表面**，不是一张会抖的画。

## 4. 对 tui-world 的设计映射

现在的 `Signal` 是"整图按行位移/缩放"（sway/breathe/push）——正是原片里没有的那种动。
应该换成**分层实时合成 + 动效词汇表**：

| 层 | 内容 | 动效来源 |
|---|---|---|
| 底 | 世界底色/氛围 | 现有 scene 程序 |
| 主角 | 素材字符画 | ① 显影（噪点→成形）② 文字剪影（轮廓内文字流动）③ 分区形变（发/衣襟/云） |
| 粒子 | 雪/灰/星/萤 | 纯函数粒子系统（可 wrap 循环） |
| 文字 | 台词字幕、计数、标签 | 打字机 + 计数滚动 + 块光标，由对话内容驱动 |
| 边框 | 状态点/活动环/进度轨 | UI 微动 |

由 LLM（视觉+文本）负责选择词汇并填参数（这就是"让模型画动画"的落点），
渲染器逐帧执行，全部是时间的函数：无缝、无限、零存储。
