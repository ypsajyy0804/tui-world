参数直说：密度=网格粗细 · 反差=明暗对比 · 去背=自动压黑背景 · 反相=白底漫画转深底发光 · 取景=裁剪范围 每项怎么调？
密度（96×64 / 120×80 / 144×96）：字符网格的粗细。96×64 粗、快，远景小物件够用； 120×80 均衡（默认）；144×96 最细，主角特写用，播放最吃资源。
反差（0.6~2.0）：明暗对比。画面发灰、主体和背景糊在一起 → 加到 1.3~1.6； 原图本来就黑硬 → 减到 0.8~1.0。
去背·容差：自动压黑"和边框连通的背景"。背景没去干净（残留色块）→ 右移加大； 主体边缘被啃掉 → 左移减小。
反相（墨线）：白底黑线的漫画专用——黑白对调，变成深底 + 发光的墨线。
取景：裁剪范围。「自动取景」按主体算；上/面/中是常用预设；也可以拖画布上的框手动调。
流程：选图（自动取景 + 可描性评分）→ 生成候选（★ 是推荐）→ 挑最像的一张 → 「AI 建议」填名字标签 → 入库。入库后回对话页，说"给我看 XX"就能上屏。
